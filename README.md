# KruSpace — โรงเรียนปากช่อง

ระบบบันทึกคะแนน เวลาเรียน ตารางสอน แลกคาบ/การลา และกิจกรรมนักเรียน
ทำงานเป็นเว็บแอปไฟล์เดียว ติดตั้งเป็นแอปบนมือถือ/ไอแพดได้ (PWA) และใช้ Firebase เป็นฐานข้อมูลกลาง

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (HTML + CSS + JS ในไฟล์เดียว) |
| `config.js` | ค่าเชื่อมต่อ Firebase และ Google (เป็นค่าสาธารณะของเว็บ) |
| `sw.js` | Service worker ทำให้ใช้งานออฟไลน์ได้ — **แก้โค้ดแล้วต้องเพิ่มเลข `CACHE_VERSION`** |
| `manifest.webmanifest` | ทำให้ติดตั้งเป็นแอปได้ |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล ต้องนำไปวางใน Firebase Console |
| `appsscript-gradebook.gs` | ทางเลือกสำรอง (Apps Script) ไม่ได้ใช้เมื่อใช้ Firebase แล้ว |
| `icons/`, `vendor/` | ไอคอนแอป และ Firebase SDK ที่เก็บไว้ในเครื่องเพื่อให้ทำงานออฟไลน์ได้ |

## การเผยแพร่

เว็บอยู่ที่ **https://boydzii.github.io/gradebook-pakchong/** (GitHub Pages)
**push ขึ้น GitHub แล้วเว็บอัปเดตเองภายใน 1–2 นาที** ไม่ต้องอัปโหลดไฟล์

```bash
git add -A
git commit -m "อธิบายสิ่งที่แก้"
git push
```

## เตือนก่อน push ทุกครั้ง

แก้ไฟล์ `index.html` แล้วอย่าลืมเพิ่มเลขเวอร์ชันใน `sw.js` (`CACHE_VERSION`)
ไม่งั้นเครื่องที่ติดตั้งแอปไว้จะยังใช้ของเก่า
